
# Attendly – Student Attendance Management System

Attendly is a web-based Student Attendance Management System designed to simplify student management, attendance tracking, and attendance reporting.

## 🚀 Features

- Admin and Student authentication
- Role-based access permissions
- Add and manage students
- Mark Present, Absent, Late, and Unmarked attendance
- Dashboard with attendance statistics
- Student attendance reports
- CSV report export
- Search and filter students
- Attendance data persistence
- Responsive user interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Node.js
- Express.js
- REST API
- GitHub Codespaces

## ⚙️ How to Run the Project

### 1. Clone the repository

```bash
git clone https://github.com/ponnarasu2805-cpu/student-attendance-management-system.git
```

### 2. Open the project folder

```bash
cd student-attendance-management-system
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the server

```bash
node server.js
```

### 5. Open the website

Open port 3001 in GitHub Codespaces.

## 👥 User Roles

### Admin

- Manage students
- Mark attendance
- View dashboard statistics
- View reports
- Export attendance reports

### Student

- Log in to the system
- View available information
- Access permitted features based on their role

## 🎯 Project Objective

The objective of Attendly is to provide a simple and user-friendly digital solution for managing student attendance and reducing manual attendance tracking.
